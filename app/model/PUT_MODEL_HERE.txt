Put your trained model file here, named exactly:

    best.pt

That's the file you downloaded from the training notebook (cell 9).
The full path should be:

    colony-counter/app/model/best.pt

Once it's here, restart the app (python main.py). It will print
"Detection engine: trained model" on startup, and the counter will use
your trained YOLO model instead of the classical CV.

If best.pt is missing, the app automatically falls back to the classical
CV detector, so it still works either way.
